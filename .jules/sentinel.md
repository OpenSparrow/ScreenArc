## 2024-05-18 - [Path Traversal in Category Directories]
**Vulnerability:** The application allowed users to specify a subfolder name for screenshot categories (`CategoryRepository.kt`), which was directly used in `File` operations without sanitization, leading to a path traversal vulnerability.
**Learning:** Even internal mechanisms creating folders based on seemingly benign entities (like user-created categories) must rigorously sanitize strings because these can be manipulated to overwrite or create files outside the intended parent directory. Furthermore, the `String.startsWith()` method is insufficient for verifying directory containment as it is susceptible to partial folder name bypasses (e.g., `/Screenshots` vs `/ScreenshotsMalicious`).
**Prevention:** Implement an explicit `sanitizeFolderName` function that uses Regex to strip all invalid and traversal characters. Always use `File.separator` suffix when utilizing string matching logic for boundary validation, or preferably use `java.nio.file.Path` methods.
